# Signal Lab

Pretend-money experiments: one $100 portfolio per signal source (Reddit, X, news, trend rules, pattern matching), a research-desk line that needs a bull thesis plus a skeptic check, buy-and-hold benchmarks (SPY, Tesla, SpaceX, Alphabet, Meta, Nvidia), and the Team Shea vs Team Nicole weekly game, on one chart.

Static site (HTML, CSS, JS) reading `data/lab.json`. Data is generated on the box by `/workspace/paper-trading/experiments/run_experiments.py` and pushed once a day at the noon ET run. No real orders are ever placed.
